# OBooks v0.2.0

Date: 2026-09-06

本版本带来书内搜索, 阅读时长统计和朗读定时, 并修好转页, 图片预览和光标等问题.

## Highlights

- 在阅读器侧栏搜索全书正文, 用 Cmd+F 打开面板, 可跳转到匹配处或分页模式下的页码.
- 主页按真实阅读时长显示今日进度, 近 14 天图表和月度打卡日历.
- 朗读播放器支持定时停止, 可选倒计时或读完本章后暂停.
- 打开书籍时先显示封面和加载指示, 图片预览与分页对齐更稳定.

## Features

- 书库: 阅读器窗口处于前台时累计时长, 失焦, 最小化或空闲 5 分钟后暂停; 数据写入 reading-stats.json, 删书时一并清除.
- 书库: 今日目标按 30 分钟显示进度, 可按书查看当日小时分布; 当天阅读满 5 分钟后点亮打卡和首页对勾.
- 阅读器: 跨章节提取正文并匹配, 展示摘录和高亮命中, 记住每本书的最近搜索.
- 阅读器: 方向键在分页模式翻页, 在滚动模式滚动; 在阅读器外 Cmd+F 聚焦书库搜索, Escape 关闭图片预览.
- 朗读: 提供 1 分钟到 2 小时的定时预设, 倒计时显示在播放器上; 本章结束时停在下一章开头, 仍可手动继续.
- 阅读器: 窗口先打开并展示封面, 首章在后台解析完成后再淡入正文.

## Bug Fixes

- 阅读器: 打开书籍时不再因缩放动画或插入符滚动把分页视图错位几像素, 初始窗口尺寸也更一致.
- 朗读: 同一页内跟随朗读时不再触发假翻页动画; 关闭窗口时停止语音, 避免拆卸期间发布状态导致异常.
- 图片预览: 点击打开不再被轻微拖动取消, 空白处点击关闭, 小图放大适配, 失焦不再退出, 并恢复触控板和滚轮平移.
- 图片预览: 放大后标题栏保持居中, 短边方向也可以拖到视口中心附近.
- 光标: 文本 I 形光标不再穿透 SwiftUI 浮层; 空白为箭头, 文字为 I 形, 图片为手形.

## Upgrade Notes

1. 运行 OBooks 仍需要 macOS 14 或更高版本.
2. 从 GitHub Release 下载新的 DMG, 将 OBooks.app 拖到 /Applications 覆盖安装.
3. 打开一本书阅读后回到主页, 确认今日时长; 在阅读器中按 Cmd+F 确认可以搜索正文.
