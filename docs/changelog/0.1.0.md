# OBooks v0.1.0

Date: 2026-09-05

OBooks 首个 macOS 版本提供原生 EPUB 阅读体验, 支持阅读设置和系统语音朗读.

## Highlights

- 导入无 DRM 的 EPUB 2 和 EPUB 3 文件并复制到应用存储.
- 使用原生 TextKit 渲染章节, 支持单栏或双栏分页和多种翻页方式.
- 在阅读器中调整主题, 字号, 行距和边距, 并保留阅读位置.
- 使用浮动播放器进行连续语音朗读, 支持句子选读和系统音色选择.

## Features

- 解析书名, 作者, 封面, spine 和 EPUB 2/3 目录.
- 支持文本选择, 高亮, 笔记和书签.
- 支持跨章节导航, 触控板跟手翻页和窗口内沉浸式控件.

## Upgrade Notes

1. 运行 OBooks 需要 macOS 14 或更高版本.
2. 首次导入 EPUB 时, 应用会将书籍复制到 Application Support.
3. 当前版本不会跨启动持久化高亮和笔记, 也不支持 DRM EPUB.
