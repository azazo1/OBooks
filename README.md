# OBooks

OBooks 是一个面向 macOS 的 EPUB 阅读器初版. 当前重点是验证阅读体验和后续跨平台架构.

## 当前能力

- 导入无 DRM 的 EPUB 2 / EPUB 3 文件.
- 解析书名, 作者, 封面, spine 和 EPUB 3 nav / EPUB 2 NCX 目录.
- 将导入内容复制到 Application Support, 不依赖原始文件位置.
- 使用 AppKit TextKit 原生渲染章节正文, 不依赖 HTML 阅读视图.
- 原生文本选择, 自定义菜单, 高亮, 笔记和实时语音范围高亮.
- 窗口内朗读播放器, 歌词式句子选读, 系统音色选择, 语速调整和跨章连续朗读.
- 朗读位置平滑跟随和自动翻页, 手动浏览停止且清除选区 4 秒后恢复跟随.
- 单栏或双栏完整分页, 支持水平或垂直翻页及跨章导航.
- 触控板跟手翻页与取消回弹, 键盘和页边点击翻页, 重排后保留阅读位置.
- 主题, 字号, 行距和边距调整.
- 顶栏, 进度栏和系统窗口按钮支持统一沉浸式显隐.
- 主页展示今日阅读时长, 近几日阅读时长和打卡日历.
- 在阅读器中搜索全书正文, 支持摘录跳转, 匹配高亮和分页页码跳转.
- 朗读播放器支持定时停止和本章结束停止.
- 方向键翻页或滚动, Cmd+F 打开搜索, Escape 关闭图片预览.
- 自部署 Go 云同步, 支持完整书库, 阅读进度, 书签, 高亮, 笔记和阅读统计, EPUB 按需下载.

## 尚未包含

- SwiftData 数据模型.
- 复杂 EPUB 的完整分页兼容.
- 固定版式漫画和童书.
- iCloud 同步和 DRM.

## 构建

需要 macOS 14 或更高版本和 Xcode 26 或更高版本.

运行构建命令:

    just build

启动应用:

    just run

工程使用 Swift Package 管理, 可以直接在 Xcode 中打开 Package.swift.

## 云同步

Go 服务端支持管理员创建账号, 多用户隔离和 HTTPS. 在客户端侧栏打开云同步设置连接服务器. 部署, 冲突处理和验证步骤详见 [云同步文档](docs/cloud-sync.md).
